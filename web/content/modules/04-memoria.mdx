Un LLM es **amnésico**: cada `.invoke()` es independiente. Para que "recuerde", tú le reenvías el historial en cada turno. La pieza que reserva ese hueco es `MessagesPlaceholder`.

<Box kind="def" label="◈ Definición · Memoria">

**Memoria**, en LangChain, no es que el modelo guarde nada. El modelo no guarda *nada*: es una función sin estado que recibe mensajes y devuelve uno. La memoria es **una estructura tuya** —una lista de mensajes— que reenvías completa en cada llamada para que el modelo "se acuerde".

Entender esto explica dos cosas de golpe: por qué la conversación cuesta más cara turno a turno (reenvías todo el historial cada vez, y pagas por token) y por qué llega un momento en que hay que resumir o recortar (la ventana de contexto se llena).

<DefList>
  <Term>MessagesPlaceholder</Term>
  <Def>El **hueco reservado** dentro del prompt donde se inyectará la lista de mensajes anteriores. Sin él, tu plantilla no tendría dónde poner el historial.</Def>
  <Term>historial</Term>
  <Def>La lista de `HumanMessage` / `AIMessage` acumulados. Vive en tu programa (una lista, una base de datos, un checkpointer), nunca en el modelo.</Def>
  <Term>thread_id</Term>
  <Def>La etiqueta que separa una conversación de otra. Dos usuarios con el mismo agente y distinto `thread_id` no se pisan el historial. Aparece a partir del Concepto 10.</Def>
</DefList>

</Box>

```python title="memoria.py · historial manual"
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage

prompt = ChatPromptTemplate.from_messages([
    ("system", "Eres un asistente amable."),
    MessagesPlaceholder("history"),   # aquí se inyecta lo ya conversado
    ("human", "{input}"),
])
cadena = prompt | llm

historial = []  # la memoria: una simple lista de Python

def chatear(texto):
    r = cadena.invoke({"input": texto, "history": historial})
    historial.append(HumanMessage(content=texto))
    historial.append(AIMessage(content=r.content))
    return r.content

chatear("Me llamo Beto y me gusta la pizza.")
print(chatear("¿Recuerdas mi nombre y qué me gusta?"))  # -> sí
```

```text title="▸ deberías ver (algo así)"
¡Claro! Te llamas Beto y te gusta la pizza.
```

Es como un chat de WhatsApp: cada mensaje ve todo el hilo arriba. Aquí tú "subes el hilo" reenviando `history`. En el Concepto 10 verás cómo LangGraph hace esto *automáticamente*.

</Box>
