### Cambiar de proveedor (Gemini ↔ Groq ↔ OpenAI ↔ Claude)

**Nada** de lo que aprendiste depende del proveedor. El resto (LCEL, tools, agentes, RAG, grafos) queda intacto. De hecho los ejemplos del repo ya no instancian ningún modelo: llaman a `util.crear_llm()`, que lee `LLM_PROVIDER` del `.env`. Si prefieres el interruptor de LangChain, es `init_chat_model`:

```python title="el interruptor universal"
from langchain.chat_models import init_chat_model

llm = init_chat_model("gemini-3.1-flash-lite")        # Google (necesita GOOGLE_API_KEY)
# llm = init_chat_model("gpt-4o-mini")           # OpenAI  (OPENAI_API_KEY)
# llm = init_chat_model("claude-sonnet-5")       # Anthropic (ANTHROPIC_API_KEY)

# Groq (y Ollama, y Together): NO hace falta una clase por proveedor.
# Todos hablan el dialecto de OpenAI; solo cambia la base_url.
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(model="qwen/qwen3-32b",
                 base_url="https://api.groq.com/openai/v1",
                 api_key=os.getenv("GROQ_API_KEY"))
```

El conmutador de `util.crear_llm()` entiende estos `LLM_PROVIDER`; si no pones `LLM_MODELO`, usa el modelo por defecto de cada uno. Cuál elegir para una solución real (pago vs. open weights, precios, dónde corre) está en el [Concepto 18b](/concepto/18b-elegir-modelo-y-proveedor).

| `LLM_PROVIDER` | Modelo por defecto | Llave (`.env`) |
| --- | --- | --- |
| `google` | `gemini-3.1-flash-lite` | `GOOGLE_API_KEY` |
| `groq` | `qwen/qwen3-32b` | `GROQ_API_KEY` |
| `ollama` | `qwen3:8b` | — (corre en tu máquina) |
| `openai` | `gpt-5.4-mini` | `OPENAI_API_KEY` |

| `deepseek` | `deepseek-v4-flash` | `DEEPSEEK_API_KEY` |

| Qué cambia | Qué NO cambia |
| --- | --- |
| La línea que crea el `llm` y la variable de entorno con la llave. | Cadenas LCEL, prompts, memoria, `@tool`, agentes, RAG, StateGraph, fallbacks, evaluación: **todo lo demás del curso**. |

Esta es la promesa central de LangChain: la **interfaz unificada** (Concepto 03). Aprendiste una sola forma de trabajar y te sirve con cualquier proveedor — incluso para poner un modelo de respaldo de otra empresa en tus `with_fallbacks`.

</Box>
